# 设计说明 · 月族偷窃掉落一览

记录这页图为什么长这样，以及**刻意避开了什么**。

## 一、原图哪里「AI 味」

两张参考图各自的问题不同，但根源是同一个：**风格不是从内容推出来的，是从「看起来专业」推出来的。**

| 维度 | 原图的做法 | 问题 |
|---|---|---|
| 配色 | 深藏青卡头 + 白卡 + 绿/蓝/紫/红/金药丸 | Tailwind 默认色板直出，颜色只做装饰不承载信息 |
| 版式 | 深色标题条 → 白卡片 → 深色标题条 → 白卡片 | 两张图共用同一套「横条 + 卡片」模板，换个内容照样套 |
| 层级 | 居中大标题 + 居中栏目标题 + 等宽两栏 | Hero + 卡片网格，最不容易出错的答案 |
| 字体 | 全篇一个黑体，靠字号拉层级 | 没有性格，也没有阅读节奏 |
| 信息编码 | 掉率写成一行文字「蜂刺 83.33% 蜂蜜 16.67%」 | 数字躺平，读者得自己心算谁高谁低 |
| 分类 | 药丸底色随机分配 | 颜色和生物门类没有稳定对应关系 |

第二张还叠了一层「新款 AI 味」：卡片圆角 + 阴影 + 灰色描边，对任何内容都套同一张皮肤。

## 二、场景推导

内容是什么：一张**对照表**——玩家在游戏里摸到一只生物，要立刻知道它能偷出什么、概率多少、值不值得偷。

给谁看、在哪用：一边玩一边看，可能开着网页或手机图片，**扫视**为主，不是从头读到尾。

所以风格应该往「**实测笔记 / 博物图鉴**」走，而不是往「科技发布会」走：

- 要能扫：概率得有视觉长度，不能只是数字
- 要能认：掉落物得有图形，光看名字反应不过来
- 要有权威感但不高冷：这是玩家的踩坑记录，不是官方文档
- 浅色纸面：长期对照阅读，深底霓虹看十分钟眼睛就累

**颜色语义固定**，全篇不许挪作装饰：

| 颜色 | 含义 | 用在哪 |
|---|---|---|
| 砖红 `#A8402F` | 敌对 | 生物名前的短标记 |
| 松绿 `#5C7A3C` | 植物 | 同上 |
| 靛蓝 `#3F6E82` | 中立 | 同上 |
| 木褐 `#7A5C2E` | 被动 | 同上 |
| 紫藤 `#6B4A8C` | BOSS | 同上 |
| 朱砂 `#9C3B27` | 偷到即死 | 概率条 + 数字 + 印章 |

## 四、概率怎么编码

原图把 83.33% 和 16.67% 并排写成文字，读者没有「量」的直觉。这里做了两层编码：

1. **条长按立方根压缩**：`width = (p/100)^(1/3)`。
   线性长度下 1% 和 7% 都缩成一根头发丝，看不出差别；立方根把低概率段拉开，
   同时保证 100% 刚好占满、视觉上「满格」的语义还在。
2. **条带疏密保留真实分级**：≥70% 实心墨、30–69% 中疏、<30% 大疏。
   数字只出现在条子右侧，用等宽字体对齐，方便纵向扫读。

这样既没有为了好看而牺牲「谁更常见」的准确直觉，也不需要读者自己做除法。

## 五、刻意避开的清单

- ✗ 蓝紫 / 靛蓝渐变、Tailwind 默认色板
- ✗ 深色卡头 + 圆角卡片 + 彩色药丸的「横条 + 卡片」模板
- ✗ Hero 居中大标题、等宽多栏、满格填充
- ✗ Emoji 当图标（用 53 个手绘 SVG，统一线宽、统一抖动手感、禁用渐变与滤镜）
- ✗ 纯平背景（feTurbulence 纤维颗粒 + 角落压暗，模拟纸面）
- ✗ 圆角（全篇 1–2px 直角，接近印刷物的硬边）
- ✗ 无意义动效、发光、粒子

保留的手工痕迹：宋体大标题的字面重量、页眉下方一长一短的双墨线、
栏目标记的短竖条、概率条的斜线网纹、即死印章的 -2° 倾斜。

## 六、成品与再生成

| 文件 | 用途 |
|---|---|
| `wortox-loot.png` | 主交付图，2480×3456（2× 缩放），9.7 MB |
| `wortox-loot-compact.png` | 96 色压缩版，5.5 MB，便于分享 |
| `index.html` | 可编辑源文件（图标已内联，单文件自包含） |
| `build.py` | 从数据 + `icons/` 重新生成 `index.html` |
| `render.py` | Chrome headless 渲染成 PNG |
| `icons/A|B|C/` | 61 个手绘 SVG 图标源文件 |

改数据的入口是 `build.py` 顶部的 `ENTRIES`，改完执行：

```powershell
python build.py     # 重新生成 index.html
python render.py    # 重新渲染 PNG
```
