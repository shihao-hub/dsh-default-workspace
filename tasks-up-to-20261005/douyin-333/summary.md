## 二、一句话结论

视频介绍的开源项目是 **青简（Qingjian）**——一个用 Rust 写的跨平台输入法，把「候选词旁顺带显示一门外语的译词」做成了输入法的一等功能，主打"每天打字顺便积累词汇"。视频本身没念出项目名，**项目名是从画面里读出来的**（安装包名 `qingjian-0.1.4-windows-x86_64-setup.exe`，以及设置页/演示中的"青简"品牌），与旁白描述逐条吻合。

## 三、项目事实（画面证据）

- **形态**：Rust 编写的开源输入法，支持 **macOS 与 Windows**（演示为 Windows x86_64）。
- **版本**：0.1.4；安装包 94.02 MB。
- **演示的安装路径**：作者把需求发给豆包，由豆包下载安装包并做完整性校验，保存到 `C:\Users\Administrator\Doubao\chats\2026-10-01\new-chat-1\`；画面显示 **SHA256 与官方 SHA256SUMS 一致**。这一步同时也是视频主推的"不会折腾 GitHub 也能用"的落地方式。

## 四、核心机制：学习功能怎么工作

1. **候选旁加一条译词**：每敲一个中文词，候选窗口右侧顺带显示该词在学习语言里的译词（画面示例：`开发 → development`、`编程 → programming`、`架构 → architecture`；`每个 → pron. each / pron. every`、`没给 → v. didn't give`）。
2. **带词性标注**：译词前标注 `n. / pron. / v.` 等词性，便于记忆用法而非只记拼写。
3. **双向**：输入英文同样给出中文意思。
4. **一次只显示一种学习语言**：设置 → 通用 → **学习语言** 可选 **英语 / 日语 / 西班牙语 / 不显示译文**；选"不显示译文"会同时关掉生词标记与释义兜底。
5. **生词标记**：候选里用书本图标标出生词，配合"释义兜底"避免出现空白。
6. **统计页**：显示今天 / 最近 7 天 / 累计的输入量与学习语言的词汇记录——把"刷到过多少次"变成可见的数字，这是"反复曝光 → 记住"这套论证的支撑点。

## 五、作为输入法本身的完整度

视频强调它不只是学习挂件，本身是完整输入法：

- **整句输入**：一口气敲完整句、中间不用选词；一句话敲完**停顿一下，本地小语言模型重排候选**（画面演示 `mei'ge'hou'xua` → "每个候选"）。
- **输入方案**：全拼、**五套双拼**、大千注音、**五笔（86 版）**，拼音与五笔可同时开着做混输；支持简拼、拼写纠错。
- **其他**：双拼在输入框显示原始击键、繁体输出等设置项。
- **可选云端联想**：开启后能"帮你把后半句接上"（演示文案中出现该表述）。

## 六、隐私与数据（画面原文要点）

- 拼音转换、词库查询、本地模型、输入统计、用户词库**全部只保存在本机，不上传**；**不需要账号**。
- 输入日志与统计分开保存；日志可在设置中关闭或清空，不影响统计。
- 唯一的联网动作是检查更新（向官网请求版本列表），且可在设置中关闭。

## 七、视频的说服逻辑（作者的论证链）

> 每天都要打字 → 学英语的时间成本几乎为零 → 高频词反复出现在眼前 → 一开始只是"眼熟" → 次数多了不用查也能反应过来 → 学习被嵌进本来就要做的事里。

这条链的成立前提是"**不额外增加动作**"：不需要打开背单词软件、不需要专门抽时间，只是顺手多看一眼。作者对效果的表述也克制——"单看一次可能没什么感觉，也不可能马上记住"，卖的是曝光频次而不是速成。

## 九、转写说明（可复现）

- 流程：`sh-zhangshihao-douyin-dl` 下载无水印视频 → `sh-video-transcribe` 转写总结。
- 模型档位：**faster-whisper small，CPU int8**，语言 zh（检测置信度 1.00），54 段。
- **注意**：`douyin_dl` 为了拿到无水印画面，在源码里主动过滤掉了抖音的 `media-audio` 流（`douyin_dl.py` 抓流处的 `!n.includes('media-audio')`），所以**首次下载到的 mp4 只有画面没有声音**，无法直接转写。本次用 CDP Network 域监听补抓音频流（`tools/net_capture.py`）→ 单独下载（`tools/fetch_audio.py`）→ `ffmpeg -c copy` 合成，才得到带音轨的 `douyin-333.mp4`。
- ASR 同音/近音错字已按语义更正（汇总时用更正后表述）：

| ASR 原文 | 更正 |
|---|---|
| 它不是苦动的拼音输入法 | 它不是**普通**的拼音输入法 |
| 它会在后选词旁边 | 它会在**候选词**旁边 |
| 显示对应的英文示意 | 显示对应的英文**释义** |
| 简拼、模糊音、双拼、中音混书 | 简拼、**拼写纠错**、双拼、**中英混输** |
| 调整后选排序 | 调整**候选**排序 |
| 专门打开被单词软件 | 专门打开**背单词**软件 |
| 单读看一次 | **单独**看一次 |
| 可能一开始只是觉得眼说 | 可能一开始只是觉得**眼熟** |
| 也能马上反映过来 | 也能马上**反应**过来 |
